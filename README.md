# Personal Portfolio Website

Personal portfolio website built with React and Vite, showcasing case studies, publications, and professional experience.

## 🌐 Live Site

[https://ananyamalik.xyz](https://ananyamalik.xyz)

## 🛠️ Tech Stack

- React
- Vite
- React Router
- CSS3
- GitHub Pages

## 📁 Structure

- **Home**: Hero section with about and services overview
- **Case Studies**: 3 detailed product case studies with individual pages
- **Publications**: 5 Medium articles on cryptocurrency and DeFi
- **Contact**: Contact information and social links

## 🚀 Development

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```
